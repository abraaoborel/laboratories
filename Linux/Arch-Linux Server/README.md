Este é meu servidor Arch.

E estarei documentando algumas etapas importantes, não pretendo fazer deste repositório um tutorial de como instalar ou um passo a passo de como instalar o Arch Linux. 

Mas usarei este espaço para aprender, errar e fazer denovo.

Pretendo documentar todo o laboratório, esta é minha primeira instalação do Arch Linux e pretendo fazer tudo na mão mesmo.

Baixei a imagem.iso no site oficial, estarei usando a VMware, coloquei a rede em modo NAT para isolar o tráfego, como não tenho poder de processamento no meu computador, estou usando 2 núcleos (meu pc tem 4), dediquei 20 gb para o vmdk (virtual machine disk), meu sistema nativo neste momento é o Windows 10.
